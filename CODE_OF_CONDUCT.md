# Code de conduite / Code of conduct

## Français

Ce projet est un loisir partagé entre amateurs d'impression 3D, de bricolage et de
Doctor Who. On attend de chacun :

- de la bienveillance et de la patience, en particulier envers les débutants ;
- des critiques qui portent sur les idées et les pièces, jamais sur les personnes ;
- aucun harcèlement, propos discriminatoire, insulte ou contenu déplacé ;
- le respect de la vie privée des autres (pas de données personnelles publiées).

Les messages qui ne respectent pas ces règles peuvent être modifiés ou supprimés, et
leurs auteurs exclus du dépôt. Pour signaler un problème, ouvrez une issue ou
contactez le mainteneur via son profil GitHub.

## English

This project is a hobby shared by 3D-printing, DIY and Doctor Who fans. Everyone is
expected to:

- be kind and patient, especially with beginners;
- criticise ideas and parts, never people;
- refrain from harassment, discrimination, insults or inappropriate content;
- respect other people's privacy (do not post personal data).

Messages that break these rules may be edited or removed, and their authors banned
from the repository. To report a problem, open an issue or contact the maintainer
through their GitHub profile.
