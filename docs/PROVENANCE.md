# Provenance et références

## Kit de référence d'origine

Le projet s'est appuyé au départ sur le **TARDIS Deluxe Kit** :

- auteur : **countspatula** (Charlesworth Dynamics) ;
- source : [Thingiverse 124033](https://www.thingiverse.com/thing:124033) ;
- licence : [Creative Commons BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/).

Le kit a servi de référence pour les proportions et les détails de la cabine. Aucun
de ses fichiers n'est réutilisé : toute la géométrie de la chatière est construite
par le code de `tardis_v8/generate.py`. Les fichiers du kit ne sont pas redistribués
ici ; on les trouve sur sa page d'origine. Par prudence, le projet reprend des
conditions compatibles (BY-NC-SA, non commercial) : voir [LICENSE.md](../LICENSE.md).

## Direction visuelle

Une image d'ambiance générée par IA d'une
chatière TARDIS montée sur une porte claire. Cette image a guidé les deux
battants, les moulures, les fenêtres, l'enseigne et la lanterne.

Cette image n'est pas dans le dépôt : toutes les images publiées sont des rendus du
modèle 3D du projet.

## Références techniques consultées

- [Gabarit de chatière SureFlap](https://www.surepetcare.com/en-ca/pet-doors/microchip-cat-flap),
  utilisé comme repère de passage courant, avant le choix de 190 × 200 mm.
- [Kit multicolore K1, documentation Creality](https://wiki.creality.com/en/k1-flagship-series/CFSUK).
- [Guide multicolore Creality et correspondance des filaments CFS](https://www.creality.com/es/help/multi-color-printing-guide).
- [Présentation Creality du kit et du volume K1 Max avec CFS](https://forum.creality.com/t/creality-s-k1-series-cfs-upgrade-kit-everything-you-need-to-know/37102).
- [Lecteur et exporteur 3MF de Creality Print](https://github.com/CrealityOfficial/CrealityPrint/blob/master/src/libslic3r/Format/bbs_3mf.cpp),
  pour les métadonnées de parties et l'affectation `extruder`.

Les informations de conception résultantes sont détaillées dans les guides et
les rapports ; les liens ci-dessus conservent la trace des sources consultées.
